# FlowPilot team test

Public static guest edition of the ENT207TC mall-navigation prototype.

Product: https://franklinnexus.github.io/flowpilot-team-test/
Guide: https://franklinnexus.github.io/flowpilot-team-test/guide.html

Two-floor 3D mall, eight destinations, search and filters, standard and step-free routes,
simulated congestion, manual waypoint navigation and journey restoration.
No account service or automatic feedback collection. Feedback is saved in the visitor's
browser and copied/downloaded for manual sharing. See THIRD_PARTY_NOTICES.md.

GitHub Pages publishes main at the repository root. All assets and links support
the project subdirectory; the service worker is scoped to this application.
